\## 高风险偏离（直接背离用户目标，必须修正）



\### 偏离 #1：编码器选 `ffmpeg\_nvenc` 而非 `obs\_nvenc`

\- \*\*位置\*\*：\[ARCHITECTURE.md](file:///c:/Users/绝绝子/Desktop/Co/window\_capture/ARCHITECTURE.md#L118) §3.1 第 118 行 `obs\_video\_encoder\_create("ffmpeg\_nvenc", ...)`

\- \*\*背离点\*\*：OBS UI 默认 N 卡编码器是 `obs-nvenc` 插件的 `jim\_nvenc`（id=`obs\_nvenc`），用户在 OBS 里选 "NVIDIA NVENC H.264" 选的就是它；`ffmpeg\_nvenc` 是 obs-ffmpeg 插件里的 FFmpeg 封装版，OBS UI 默认不选它

\- \*\*后果\*\*：锁模型（阻塞 lock + gate 门控 + 稳态 1 帧）是 obs-nvenc 的实现，ffmpeg\_nvenc 走 FFmpeg avcodec 路径，没有 OBS 那套 NVENC 锁模型——你之前在 capture-src 里辛辛苦苦对齐的 OBS NVENC 锁模型，在这条路径下\*\*根本不生效\*\*



\### 偏离 #2：`build.ps1` 关闭 obs-nvenc 插件

\- \*\*位置\*\*：\[build.ps1:302](file:///c:/Users/绝绝子/Desktop/Co/window\_capture/build.ps1#L302) `-DENABLE\_NVENC=OFF`，注释说"obs-nvenc 编译需 CUDA SDK（obs-deps 不含）→ 关闭避免 BUILD 失败"

\- \*\*后果\*\*：obs-deps 2026-06-25 已含 FFnvcodec 12 头，打开 `-DENABLE\_NVENC=ON` 即可，根本不会 BUILD 失败。这个错误前提导致整个项目从根上选错了编码器路径

\## 中风险偏离（凭空发明 OBS 没有的机制）



\### 偏离 #5：push 模式的 drop-on-overflow 队列

\- \*\*位置\*\*：\[ARCHITECTURE.md §5](file:///c:/Users/绝绝子/Desktop/Co/window\_capture/ARCHITECTURE.md#L246-L286) 整章 + §4.2 第 219-220 行

\- \*\*背离点\*\*：OBS 自己的输出层（包括自定义 output）走的是 `obs\_output\_encode\_packet` → output 实现的 `encoded\_packet` 回调，OBS 没有"满则丢最旧帧"这种背压策略。OBS 的输出层是同步回调——OBS 调你的 `encoded\_packet(pkt)`，你处理完返回，OBS 再继续；如果慢，OBS 编码器会自然背压（gate 门控），而不是你这边丢帧

\- \*\*后果\*\*：这是凭空发明的机制，引入了 OBS 不存在的丢帧语义；而且 §5 自己也承认这是"最关键隐患"——既然是凭空实现的，那这个隐患本身就是这个设计的产物，不是 OBS 的固有行为



\### 偏离 #6：自定义 `wc\_pipe` output + BSF 转换层

\- \*\*位置\*\*：\[§4.2](file:///c:/Users/绝绝子/Desktop/Co/window\_capture/ARCHITECTURE.md#L191-L235) + \[§4.3](file:///c:/Users/绝绝子/Desktop/Co/window\_capture/ARCHITECTURE.md#L237-L242)

\- \*\*背离点\*\*：OBS 的 `ffmpeg\_hls\_muxer` / `ffmpeg\_mpegts\_muxer` 内部通过 `AVFMT\_FLAG\_AUTO\_BSF` 自动做 AVCC→Annex-B。自己实现 wc\_pipe output + 自己持有 AVBSFContext，相当于把 OBS muxer 内部的 BSF 逻辑重写一遍

\- \*\*后果\*\*：这是必要的（因为绕过了 muxer），但本质上是"自实现"——和用户"避免自编译 exe 需要调试大量 bug"的初衷有张力。一个折中是直接用 OBS 的 `ffmpeg\_mpegts\_muxer` 或 `ffmpeg\_hls\_muxer` 输出到管道，让 OBS 的 muxer 自己处理 BSF，避免自实现 BSF 转换层

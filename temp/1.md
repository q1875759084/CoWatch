💡 CoWatch 的正确架构

Plain Text

当前错误架构（❌）：
FFmpeg 一把梭 → 视频(ddagrab) + 音频(dshow/wasapi) → 用户要装驱动

正确架构（✅）：
┌─────────────────────────────────────┐
│  视频录制：FFmpeg ddagrab/gfxcapture │ ← 继续用 FFmpeg
│  音频录制：Node.js 原生 WASAPI       ← 新增！不依赖 FFmpeg
│         ↓                           │
│  合并：ffmpeg 合并音视频流            │
└─────────────────────────────────────┘
🔧 实现方案
方案 A：用 node-record-lpcm16 + WASAPI（推荐⭐）

Bash

npm install node-record-lpcm16
这个库底层调用 Windows WASAPI，不需要额外安装任何东西！

方案 B：用 mic 库（更简单）

Bash

npm install mic
支持 loopback 录制。

方案 C：自己编译带 WASAPI 的 FFmpeg 打包进 CoWatch
在 electron-builder 配置中打包自定义编译的 ffmpeg.exe（包含 wasapi），用户无感知。

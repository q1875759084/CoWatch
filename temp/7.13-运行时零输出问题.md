# 问题记录：window_capture.exe 运行时零输出（已解决）

- 记录时间：2026-07-13 21:50
- 关联模块：`electron/bin/capture-src/`（方案 2a：WGC 窗口录屏 + WASAPI 音频 + NVENC 硬编码）
- 状态：**已解决** ✅（根因 = 部署漏拷 `swresample-6.dll`）

---

## 1. 现象

```
.\window_capture.exe --pid 31676 --mux-target null --stats
```
- PowerShell 下**零输出**、命令提示符立刻返回（无 READY / 无 ERROR / 无异常提示）
- 三处 `cowatch_boot.log`（C:\ / 当前目录 / %TEMP%）均不存在 → 进程在 `main()` 之前退出
- 事件查看器无 Application Error 崩溃记录

---

## 2. 根因（已确认）

**`avcodec-62.dll` 在运行时还导入 `swresample-6.dll`**（`dumpbin /dependents avcodec-62.dll` 末行可见），但部署时只拷了 `avcodec-62.dll` + `avutil-60.dll`，**漏掉 `swresample-6.dll`**。

`window_capture.exe` 把 `avcodec-62.dll` 列为直接导入 → 加载器解析它时需要 `swresample-6.dll` → 找不到 → 进程在 `main()` 之前以
**STATUS_DLL_NOT_FOUND（NTSTATUS 0xC0000135 = -1073741515）** 静默终止。

- 这一 loader 错误**不弹对话框、不写事件日志、无 stdout**，正好对应"零输出 + 无 boot 日志"现象。
- `nvEncodeAPI64.dll` 不是元凶：它在 System32 真实存在，自身依赖仅 WINMM/KERNEL32/ADVAPI32/ole32（全在）。

---

## 3. 验证（关键：拿真实退出码）

`Start-Process` + `[int]$p.ExitCode` 在部分上下文会读成空/0（PowerShell 怪象），误导判断。
最可靠是在前台 `-Wait` 跑一次读真实退出码：
- 修复前：`EXIT_CODE_FROM_PROC = -1073741515`（0xC0000135，缺 DLL）
- 修复后：`{"type":"LOG","msg":"window_capture started"}` / `{"type":"LOG","msg":"args parsed"}` / `{"type":"ERROR","code":2,"msg":"no visible window for pid"}` → 加载器已过关、main() 已执行

---

## 4. 修复

1. **部署补齐**：从 `FFMPEG_ROOT/bin/swresample-6.dll` 拷到 `electron\bin\`（与 avcodec/avutil 同目录）。
2. **防复发**：`build.ps1` 已增加"拷贝 FFmpeg 运行期 DLL（avcodec-62/avutil-60/swresample-6）到 electron/bin"步骤，重建自动补齐。

---

## 5. 排查手法（沉淀）

定位"main 前静默退出"：
- 优先拿**真实退出码**（前台 `-Wait` 跑，而非依赖 PowerShell 的 `$p.ExitCode`）。
- 对 `dumpbin /dependents` 列出的**每个直接导入 DLL，递归查其传递依赖**是否都在 exe 同目录 / PATH / System32。**缺失的往往是传递依赖**（本例 swresample-6），而非顶层列表里那些。

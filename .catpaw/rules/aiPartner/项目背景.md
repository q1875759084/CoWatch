# CoWatch 项目背景

## 产品定位

CoWatch 是一个**多人游戏录屏同步复盘平台**。房主创建房间并上传录屏，受邀成员通过分享链接免注册加入，所有人实时同步观看同一视频，支持带权限管理的进度条控制。

## 用户与角色

| 角色 | 说明 |
|------|------|
| 管理员 | 房间创建者，可上传视频、切换控制模式、指定控制者 |
| 成员 | 通过邀请链接加入，无需注册，输入昵称即可 |

**身份方案：** 无账号体系，UUID 存 localStorage，刷新页面可恢复身份。

## 技术栈

| 端 | 技术 |
|----|------|
| 前端 | React 19 + Webpack 5，Node 20 |
| 后端 | Node.js 20 + Express + ws 库 + SQLite（better-sqlite3） |
| 视频存储 | 阿里云 OSS，前端预签名直传 |
| 实时通信 | WebSocket（ws 库），服务端广播房间事件 |

**项目结构：** 前后端分离，非 Monorepo。`frontend/` 和 `backend/` 各自独立。

## 功能模块

| 模块 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 创建房间 / 输入房间码加入 |
| 等待室 | `/room/:roomId/lobby` | 上传视频、查看成员、等待开始 |
| 复盘房间 | `/room/:roomId/watch` | 多人同步视频播放、控制权管理 |

## 控制权机制

- **指定模式（默认）**：管理员指定某成员为进度控制者
- **自由模式**：任意成员可操作进度条，最后写入者生效
- 管理员可随时通过开关切换两种模式
